# columns-share-bar

Custom **columns** block. Purpose: Article utility row with share links, a download-assets dropdown and a subscribe button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with three cells: cell 1 the label 'Share' and a list of share links or network names (X, Facebook, LinkedIn, Email); the block rebuilds each share URL from the current page URL and title. Cell 2 the dropdown label (e.g. 'Download assets') as a paragraph followed by a list of download links (e.g. 'Download release (PDF)'). Cell 3 a single link (e.g. 'Subscribe to AT&T News'), rendered as a button.

## Supported variations

| Variation | Option class |
| --- | --- |
| Three Cells | `three-cells` |
| Share Icons | `share-icons` |
| Dropdown | `dropdown` |
