# accordion-expand-text

Custom **accordion** block. Purpose: Small-print text collapsed behind a plain text-link toggle.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per collapsible section with two cells: cell 1 the toggle label as plain text (e.g. 'Disclaimers', 'View more'), cell 2 the hidden content (paragraphs, footnotes with superscript numbers, links).

## Supported variations

| Variation | Option class |
| --- | --- |
| Text Link Toggle | `text-link-toggle` |
| Small Print | `small-print` |
