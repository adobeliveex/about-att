# quote-plain

Custom **quote** block. Purpose: Pull quote in body-text style with the attribution inline.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1, one cell: the quotation paragraph(s), which may already include the inline attribution with the speaker in bold. Row 2 (optional), one cell: a separate attribution; with inline-attribution it is appended to the end of the last quotation paragraph.

## Supported variations

| Variation | Option class |
| --- | --- |
| Inline Attribution | `inline-attribution` |
