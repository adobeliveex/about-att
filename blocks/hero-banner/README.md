# hero-banner

Custom **hero** block. Purpose: Page-leading banner: full-bleed image with the main headline and a CTA overlaid.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2: h1 headline, optional text, and a standalone link (rendered as a button).
