# embed

Embeds a video or social post from a link (from the AEM Block Collection). Supports YouTube, Vimeo and X/Twitter; other URLs are embedded in a plain iframe. The player loads only when the block scrolls into view.

## Authoring (Document Authoring)

Model: `standalone`

One cell: the link to the video (e.g. `https://www.youtube.com/watch?v=...`). Optionally put an image before the link to show it as a placeholder with a play button; the video then loads when clicked.

## Supported variations

None.
