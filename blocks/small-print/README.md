# small-print

Footnotes, disclaimers and "About AT&T" boilerplate at the foot of a story, shown in the about.att.com small-print style (15px text, 27px line height, left-aligned). Use it for text that is visible on the page; for small print hidden behind a "Disclaimers" / "View more" toggle use Expandable Small Print (accordion-expand-text).

## Authoring (Document Authoring)

Model: `standalone`

| Small Print |
|---|
| Rich text: paragraphs, lists, links, superscript footnote numbers |

Extra rows are allowed; their content is joined in order.

## Supported variations

None.
