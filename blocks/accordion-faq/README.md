# accordion-faq

Custom **accordion** block. Purpose: Expand/collapse FAQ list of questions and rich answers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per question with two cells: cell 1 the question text, cell 2 the answer (paragraphs, lists, links). The FAQ heading stays default content above the block.

## Supported variations

| Variation | Option class |
| --- | --- |
| Chevron | `chevron` |
| Divider Rows | `divider-rows` |
