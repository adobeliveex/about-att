# cards-news

Custom **cards** block. Purpose: Grid of news story cards with image on top, title, description and a text Learn more link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per story: cell 1 image (optionally linked), cell 2 h3 title, description paragraph and a Learn more link. With load-more, cards are revealed six at a time behind a View More button.

## Supported variations

| Variation | Option class |
| --- | --- |
| 3 Up | `3-up` |
| Image Top | `image-top` |
| Text Link CTA | `text-link-cta` |
| Load More | `load-more` |
