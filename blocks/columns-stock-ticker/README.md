# columns-stock-ticker

Custom **columns** block. Purpose: Compact one-line stock ticker band: price, change, timestamp and a link to stock information.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with four cells: price (e.g. T: $21.85) | change (e.g. ↑ $+0.05) | timestamp | link (View stock information). Optional extra single-cell row with a link to a .json feed for the live-data option.

## Supported variations

| Variation | Option class |
| --- | --- |
| Four Cells | `four-cells` |
| Inline | `inline` |
| Live Data | `live-data` |
