# search-newsroom

Custom **search** block. Purpose: Inline newsroom search bar with a magnifier submit button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell with a link to the search source (a query-index .json filters in place; any other URL is a results page submitted with ?q=) and the placeholder text as a separate paragraph. Key/value rows (source | url, placeholder | text) also work.
