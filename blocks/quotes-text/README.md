# quotes-text

Story quotation with the AT&T blue quotation-mark graphic beside it, as on about.att.com story pages. Desktop: an 817px row with a 209px quote-mark column (189 x 149 mark plus a 20px gap) and the quote text beside it (21px). Mobile (under 600px): a wide quote mark above the text (18px).

## Authoring (Document Authoring)

Model: `standalone`

| Quotes Text |
|---|
| "Quote text," said **Name, title, Company**. "More quote text." |

- One row per quote; several rows stack with the source spacing.
- The blue quotation mark is built in: authors only add the text.
- Optional: put an image in a first column to replace the quote mark for that row.
