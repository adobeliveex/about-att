# offer-banner

Promotional banner used in offer fragments (`/fragments/offers/...`) to advertise AT&T offers on the newsroom. Two looks, chosen by the content:

- **Text banner** (no image): centred on a light AT&T blue, rounded panel (att.com offer strip).
- **Image banner** (an image is authored): business.att.com hero offer. Desktop: the photo covers the rounded panel and the text sits left in white with a light pill button. Mobile: the photo sits above dark text and a filled blue button.

## Authoring (Document Authoring)

Model: `standalone`

| Offer Banner |
|---|
| **Heading** (e.g. Try AT&T Wireless<sup>SM</sup> FREE for 30 days) |
| Description paragraph |
| Legal paragraph(s), may end with a link such as "See offer details" |
| A link on its own line for each button (e.g. Learn more) |

All in one cell (or one row per part), in that order:
- optional: the background photo; add a second image to use a different crop on mobile
- optional: an eyebrow line before the heading (e.g. "AT&T Business deals")
- the heading (use superscript for SM / TM marks)
- the first paragraph is the description
- any further text paragraphs are the legal / offer terms (small print)
- a paragraph containing only a link becomes an outline button
